Place optional file-association assets here.

Supported files:
- `md.ico` for `.md`
- `markdown.ico` for `.markdown`
- `text-markdown-64.png`, `text-markdown-128.png`, `text-markdown-256.png`, `text-markdown-512.png` for Linux MIME icons
- `markdown-editor-pro.xml` for the Linux shared MIME package

If a Windows `.ico` file is missing, the build falls back to the app icon for that extension.
